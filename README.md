# 小米笔记 · PI-Desktop 插件

把小米云笔记做成 PI-Desktop 里的图形化工作面板，并让 AI 直接读写你的笔记。

**笔记能力全部内置，不需要配置任何 MCP 服务器。**

[English](README.en.md) · [开发者文档](CONTRIBUTING.md)

---

## 安装

从本仓库的 [`dist/`](dist) 目录下载最新的 `.piplug` 安装包
（文件名形如 `local.mi-note-<版本>.piplug`），在 PI-Desktop 插件页安装即可。
也可以从 [Releases](../../releases) 下载历史版本。

## 使用

1. 命令面板搜「小米笔记」，打开面板。
2. 面板显示二维码 —— 用小米手机「设置 → 小米账号 → 扫一扫」扫描并确认。
3. 自动完成登录与首次同步，开始用。

**不需要密码**，也不受图形验证码 / 两步验证影响。

## 功能

**扫一扫登录** —— 手机扫码确认即可，二维码 5 分钟有效，过期点「重新获取」。

**一键退出登录** —— 面板右上角「退出」，确认后清空本机凭据与缓存，并直接回到扫码界面。
云端笔记不受影响，重新登录会自动同步回来。右上角同时显示当前版本号。

**两栏界面** —— 左侧笔记列表 + 右侧正文。文件夹收进列表栏顶部的下拉框，
把纵向空间留给笔记本身。深色 / 浅色跟随宿主主题自动切换。

**笔记管理** —— 浏览、搜索（标题与正文）、新建、编辑（Markdown，带预览）、删除。
搜索结果会在列表与正文里**高亮**，并自动滚到正文的第一处命中。

**大纲** —— 正文右侧可开关的目录（H1–H5），滚动时自动高亮当前所在小节，点击即可跳转。

**导出** —— 「导出」按钮可把当前笔记取走：**Markdown 源码**（纯文本，粘到任何编辑器
存成 `.md`）或**自包含 HTML**（样式、代码高亮、公式字体、附件图片全部内联进单文件，
粘到 `.html` 里即可离线打开，不联网也不缺东西）。可切深色配色。
导出走系统剪贴板，**不新增任何文件读写权限**。

**导入** —— 「导入」按钮可把本机的 Markdown 批量搬进小米笔记：一次多选 `.md` 文件，
或选整个文件夹**递归导入**（可勾选「保留子文件夹结构」，按来源目录在小米笔记里建出
同名文件夹，同名目录自动复用）。也可以直接把文件或文件夹**拖进面板**。
标题按「front matter 的 `title` → 首个一级标题 → 文件名」取值。
**不新增任何文件读写权限** —— 文件由你在系统文件选择器里显式选中后交给面板读取。

**Markdown 预览** —— 标题、表格、嵌套列表、任务列表、引用、代码块（**语法高亮**）、
数学公式（KaTeX，行内 `$…$` 与块级 `$$…$$`）、图片、下划线与高亮底色，都能正确显示。
笔记里的图片会按需下载并缓存到本地，离线也能看。

**写作辅助** —— 编辑区带工具栏（粗体 / 斜体 / 标题 / 列表 / 任务 / 引用 / 链接 / 图片 /
代码块 / 表格），Tab 缩进与反缩进，列表回车自动续行（有序列表数字自增，空项回车退出列表）。
快捷键：`Ctrl/Cmd+B` 粗体、`Ctrl/Cmd+I` 斜体、`Ctrl/Cmd+K` 链接、`Ctrl/Cmd+Shift+C` 行内代码。
**所有操作都支持 `Ctrl/Cmd+Z` 撤销。**

**自动保存** —— 改完不用点保存，1.5 秒自动存盘。切换笔记时先把草稿写完再切，
**不会丢草稿**。中文输入法打字过程中不会保存，不会把拼音存进云端。

**删除可撤销** —— 删除后笔记立即消失，底部出现 6 秒「撤销」窗口，反悔了来得及。

**AI 问答** —— 基于你的笔记内容回答，用 PI-Desktop 已登录的模型，插件拿不到任何密钥。
只把检索命中的片段送进上下文，不是全部笔记。

**自动同步** —— 每 5 分钟增量同步一次，只重取变化的正文。登录态失效时面板会
明确提示，重新扫一次码即可；不需要手工复制 Cookie。

### 侧边栏

右侧工作面板里的紧凑笔记列表：

- 点标题即在侧边栏内阅读全文
- 每项右侧按钮可在主面板中打开并定位到该篇
- 阅读界面顶部有「复制全文」，方便粘到对话框

### AI 可以直接操作你的笔记

插件内置 10 个工具，AI 能读取、搜索、创建、修改、删除笔记，无需任何额外配置。

## 常见问题

**会泄露我的笔记吗？**
不会。插件只与 `i.mi.com` / `account.xiaomi.com` 通信；本地只写插件自己的数据目录，
不读也不写你的工作区文件。AI 问答只把检索命中的片段交给宿主已登录的模型。

**密码安全吗？**
插件全程不接触密码 —— 扫码登录由手机端确认，凭据以 0600 权限存在插件私有目录。

**支持哪些平台？**
跟随 PI-Desktop，桌面端（Windows / macOS / Linux）。
