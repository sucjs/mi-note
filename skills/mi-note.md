# 小米笔记

用户的小米云笔记。所有能力由 `pi.mi-note` 插件内置提供 —— **不需要配置任何 MCP 服务器**。

## 工具

| 工具 | 用途 |
| --- | --- |
| `list_folders` | 列出文件夹与各自的笔记数 |
| `list_notes` | 列出笔记（可按 `folderId` 筛选、按 `query` 搜索、分页） |
| `read_note` | 读一篇的完整 Markdown 正文 |
| `search_notes` | 在标题与正文里搜关键词，返回命中片段 |
| `create_note` | 新建笔记（正文用 Markdown） |
| `update_note` | 改正文 / 标题 / 所属文件夹 |
| `delete_note` | 删除（默认进回收站） |
| `create_folder` | 新建文件夹 |
| `sync_notes` | 立即从小米云同步 |
| `note_status` | 查登录状态、笔记数量、上次同步时间 |

## 怎么做

- **先看有没有登录**：如果工具报「还没有登录」，不要在对话里追问账号密码 —— 直接让用户
  打开「小米笔记」面板（命令面板搜「小米笔记」）用手机扫码，然后重试。
- **要全文一定走 `read_note`**：`list_notes` 只给摘要。回答内容性问题前先读原文，
  不要凭摘要猜。
- **写之前先读**：`update_note` 的 `markdown` 是整体替换。改一篇已有笔记前，
  先用 `read_note` 拿到当前内容，改动后提交完整正文。只想改标题就不要传 `markdown`。
- **删除要留余地**：默认进回收站。只有用户明确说「彻底删掉 / 永久删除」才传 `purge: true`。
- **数据是同步自云的**：插件每 5 分钟自动增量同步一次。用户说「我刚在手机上记的」
  而工具里没有时，先 `sync_notes` 再查。
- **正文格式**：工具返回与接收的都是 Markdown。小米笔记自己的 XML 格式由插件双向转换，
  不要手工构造小米的 XML 标签。

## 边界

- 只处理小米云笔记。用户没要求时，不要把这些工具用在别的笔记应用上。
- 笔记是用户的私人内容。除非用户要求，不要把笔记正文大段复述给第三方或写入其他文件。
